权限治理视图

当前权限矩阵：普通用户禁用后台监控/用户管理/审计；三员各司其职。

· user 普通用户：业务全功能，禁监控/用户管理/系统配置/审计日志
· sysadmin 系统管理员：业务 + 用户管理 + 系统配置 + 后台监控 + 知识库文件删除（禁审计日志）
· secadmin 安全保密员：业务（含知识库写）+ 后台监控 + 知识库文件删除；专属＝敏感标记
· audadmin 审计员：全局只读 + 审计日志（未来接入）
监督关系：sysadmin 建号/配系统 → secadmin 保密与授权 → audadmin 全程审计，三权分立、互相制衡。
